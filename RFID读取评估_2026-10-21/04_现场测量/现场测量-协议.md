# 现场测量协议 —— 卡通箱 RFID 读取能力

> 目标：用**同一套口径**回答四个问题 —— 朝向影响、模块差异（6 dB / 9 dB）、距离影响、厂商差异。
> 所有读取数据用 `rfidmon`（自研 LLRP 客户端）采集，输出 `records-<日期>.jsonl`，可逐条复核。

---

## 0. 箱体面定义（现场必须先统一）

| 面 | 特征 | 代号 |
|---|---|---|
| **正面**（长×高） | 有**防爆标识** | `F-FRONT` |
| **背面**（长×高） | 有**箱体条码 + 6 个整机序列号** | `F-BACK` |
| 侧面（宽×高） | 无标识/仅物流标 | `S-LEFT` / `S-RIGHT` |
| 顶面、底面（长×宽） | 封箱带 | `T-TOP` / `B-BOTTOM` |

> 注意：**正面与背面都是"长×高"**，肉眼最容易混。每张照片请同时在箱面贴上 `F-FRONT`/`F-BACK` 纸标再拍。

---

## 1. 测量前固定项（不要随测试变动）

| 项 | 设定 |
|---|---|
| 读码器固件/型号 | 记录铭牌（厂商 + 型号 + 功率档 6 dB / 9 dB） |
| 发射功率 | 固定 `TxPower = 30 dBm`（如需对比功率档，单列一组） |
| 会话 / 盘点模式 | 固定 `Session 2`、`DualTarget` |
| 天线 | 固定只用同一支天线（记录天线号），其余禁用 |
| 每档采样时长 | **≥ 30 秒**，且至少 3 箱通过/放置 |
| 环境 | 记录是否有金属托盘、附近其他读码器、人员走动 |

## 2. 测试矩阵

### 2.1 朝向（A 组）

| 编号 | 箱体姿态 | 哪个面接触/朝向读码器 | 备注 |
|---|---|---|---|
| A1 | 正立 | 底面 `B-BOTTOM` 朝下，读码器在**下方** | 产线实际姿态 |
| A2 | 正立 | 正面 `F-FRONT` 朝读码器（读码器在侧面） | |
| A3 | 正立 | 背面 `F-BACK` 朝读码器 | 序列号面 |
| A4 | 侧放（长×高面朝下） | 正面朝下 | 关键：标签是否被箱体遮挡 |
| A5 | 侧放 | 背面朝下 | 关键：条码面朝下 |
| A6 | 倒置 | 顶面朝下 | |

### 2.2 距离（B 组，姿态固定为 A1）

| 编号 | 读码器位置 | 距离（cm） |
|---|---|---|
| B1 | 上方 | 0 / 5 / 10 / 20 / 30 / 50 |
| B2 | 下方 | 0 / 5 / 10 / 20 / 30 / 50 |
| B3 | 侧面（正面） | 0 / 5 / 10 / 20 / 30 / 50 |
| B4 | 侧面（背面） | 0 / 5 / 10 / 20 / 30 / 50 |

> "0 cm"= 天线面紧贴箱面（不压箱）。

### 2.3 模块/厂商（C 组）

每换一个模块，重复 A1–A6 与 B1–B4 中**最关键的 3 档**（0 / 10 / 30 cm）。

## 3. 每档要记的数字

| 指标 | 取法 |
|---|---|
| 读到几个 distinct EPC | `records-*.jsonl` 里该时间窗去重计数 |
| 6 个整机标签是否读全 | 与箱面 6 个序列号逐一对照（缺哪个记下） |
| 读取率 | 条/秒（窗口内条数 ÷ 秒数） |
| RSSI 范围 | min / max / 平均 |
| 天线命中分布 | 各天线条数占比（判断是否需要多天线） |
| 误读/串读 | 是否读到邻箱或其他标签 |

## 4. 取数命令（办公机远程，或现场本机）

```bash
# 起监测（会占用读码器会话；产线软件此时无法自读 —— 测试窗口内可接受）
python ctl\ompremote.py rfid 7H3AA-PALLET start

# 测试期间看实时尾巴
python ctl\ompremote.py rfid 7H3AA-PALLET tail -n 30

# 测试结束：把这一段时间的 jsonl 拉回来
python ctl\ompremote.py fetch 7H3AA-PALLET -p "\\10.32.134.128\mbd3md3_basin\TBZ\_omp\machines\7H3AA-PALLET\rfid\records-*.jsonl" --dest .\rfid-tests

# 归还读码器给产线软件
python ctl\ompremote.py rfid 7H3AA-PALLET pause
```

如果现场换模块后读码器 IP 变了：改 `D:\HQ Package System V2\Setting\SettingPrm.xml` 的 `<rfidSetting><Ip>`，
或直接 `rfidmon.exe --ip <新IP>`（`rfid stop` 后重启）。

## 5. 记录表

见同目录 `现场测量记录表.csv`（每档一行）。列含义：

| 列 | 含义 |
|---|---|
| `case_id` | A1/B1-10/C-R420 这样的编号 |
| `face_down` / `face_toward_reader` | 接触底面 / 朝向读码器的面 |
| `reader_vendor` / `reader_model` / `reader_gain_db` | 读码器厂商、型号、功率档（6 或 9） |
| `antenna` | 天线号 |
| `distance_cm` / `position` | 距离、位置（上/下/侧） |
| `distinct_epc` / `unit_tags_read_of_6` | 去重标签数 / 6 个整机标签读到几个 |
| `reads_per_sec` / `rssi_min` / `rssi_max` | 读取率与 RSSI |
| `photos` | 照片文件名（务必含面标） |
| `note` | 异常（遮挡、金属、多人走动…） |

## 6. 拍照清单（报告要用）

1. 箱体**正面**（防爆标识）全貌 + 卷尺
2. 箱体**背面**（条码 + 6 序列号）全貌 + 卷尺
3. 每种放置方式（A1–A6）：箱体 + 读码器**同框**，能看到距离
4. 每个模块/读码器铭牌特写
5. 距离档位（0/10/30 cm）侧视同框图
6. 读码器安装方式（支架/龙门）整体图

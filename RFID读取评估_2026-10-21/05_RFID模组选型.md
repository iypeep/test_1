# RFID 模组 / 读码器选型清单（2026-10-21 整理）

> 先澄清术语：你说的 **“9 dB / 6 dB”更可能是天线增益（dBi）**，不是读码器参数。
> UHF 圆极化天线常见 **6 dBi / 9 dBi**；增益越高波束越窄、读距越远但对位越敏感。
> 读码器（模块）的规格通常是**输出功率 30 dBm（1 W）/ 33 dBm**、接收灵敏度、天线口数。
> 报告里建议分开写：`读码器型号 + 输出功率` 与 `天线型号 + 增益(dBi) + 极化方式`。

---

## 1. 形态分类（先定形态，再选型号）

| 形态 | 说明 | 接口 | 适用 |
|---|---|---|---|
| 嵌入式模组 | 只有射频板，需自制底板/天线 | UART / SPI / USB | 集成进设备，成本低，需硬件能力 |
| 工业读头（分体式） | 模块+外壳+多天线口，天线外接 | RS232/485、以太网、GPIO | 产线固定安装（本项目最像这种） |
| 一体机 | 读头+天线一体 | 以太网/串口 | 近距离单点 |
| 手持/移动 | 手持终端或 PDA 模块 | 蓝牙/WiFi | 抽检、盘点 |

## 3. 标签侧（决定“能不能读到”的另一半）

| 项 | 现场现状 | 说明 |
|---|---|---|
| 芯片 | Impinj **Monza R6-P**（实测 TID `E2801170…`） | 灵敏度好，常见工业标签 |
| EPC 长度 | 设备标签 14 字节（非标）；另有 12 字节 96-bit 标签 | 长度不影响读距，但影响编码方案 |
| 频段/协议 | UHF 860–960 MHz，ISO 18000-6C (Gen2) | 与读码器必须一致 |
| 安装介质 | 纸箱（瓦楞） | 纸箱对 UHF 衰减小；**若贴金属/液体旁会显著掉读距** |

---

## 4. 选型要问供应商的 8 个问题

1. 输出功率范围（dBm）与是否可调？多天线口？
2. 接收灵敏度（dBm）？
3. 支持 Session 1/2/3、DualTarget / SingleTarget？
4. 盘点速率（tags/s）实测值（不是理论值）？
5. 接口与供电（PoE？24V？）、防护等级（IP）？
6. 是否支持 RSSI / 相位 / TID 上报（做能力评估必须有）？
7. SDK/API（.NET / C / REST），是否有 LLRP 标准口？
8. 价格 + 交期 + 现场调试支持。

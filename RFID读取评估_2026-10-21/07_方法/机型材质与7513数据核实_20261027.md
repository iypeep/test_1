## 2. MES 报文里有没有材质/背壳字段？→ 没有

`MesStart` 返回的完整字段（28 个，2026-10-27 01:24 一箱）：

```
AmazonSetName, BarcodeList, BoxQty, Build, CongfigSize, DDR,
DSN, DSN1…DSN10, Device_Weight, EmptyBox, G_CHECKFLOWID, G_WO_GUID,
G_WOID, MODEL, Progrom, SETTINGNAME, SSCC, WeightRate, eMMC
```

无 `Material` / `Shell` / 背壳 类字段（全日志扫描：`Material=0`、`Shell=0`）。
所以**用中箱码批量查询也查不到金属/塑料** —— 能查到的是机型、配置名、6 个 DSN、箱重。

材质目前只能从 `CongfigSize` 的**文字**里读，而这只对部分机型有效：

| 机型 | CongfigSize 样例 | 能否读材质 |
|---|---|---|
| AX8252 | `eReader-AX8252A/Amaxxx 低配黑白屏(Plastic）_STEALTH GREY` / `…PREM BW display (Metal)_PANDAN GREEN…` | ✅ 带 (Plastic) / (Metal) |
| AX7907 | `eReader-AX7907A/Prosexxx` 、`…/Ube Purple` | ❌ 不带材质（65 种 SETTINGNAME 全是这个写法） |
| AX6727 | `ASSY,DEVICE,BASE,BW,GREEN,SANGRIA(低配黑白)` | ❌（但有 `KKE` 字段可拆 KKE/N-KKE） |
| AX7513 / AX7771 | 从未包装，取不到 | — |

## 3. 那 7907 的塑料/金属怎么分？→ 需要外部输入

日志侧能做的都试过了：

- 65 个 `SETTINGNAME`（AX7907AAA031/032/035/036/066/080/081…）**不带材质语义**，只能看出颜色/屏幕（Ube Purple / Prosexxx）；
- 读取表现也分不开：7907 整体 `readStatus=True 9.4%`、一箱 0 台 99.1% —— 若真有金属版，按 8252 的经验（金属更差）应能看到双峰，但 54,810 箱里没有；
- 中框 vs 背壳（标签位置）同样无法从日志判断。

需要的输入（任一即可）：

1. **机型材质对照**（事业部/客户文档，或用户给的手册链接内容）→ 直接落表；
2. 或 **MES 侧另一个接口**（如物料主数据/`GetPartInfo`）—— 当前包装程序只调 `MesStart`，没有材质；
3. 或 **实物/标签照片**：同一时段抽 1 箱拆看背壳（用户提示"同一时段背壳大概率相同"，所以每段 1–2 箱即可）。
